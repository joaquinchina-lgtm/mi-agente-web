Diccionario del buscador

Aquí se edita lo que el buscador de la home entiende: los conceptos que definen cada servicio y las expresiones coloquiales que traducen a esos conceptos.

Cómo se publica un cambio. Esta página edita en memoria y guarda un borrador en este navegador. Para que llegue a la web hay que descargar el fichero con «Descargar buscador.json», sustituir con él assets/buscador.json en tu carpeta y hacer git add . && git commit && git push.

Peso de un concepto. 3 = si aparece esto, es este servicio. 2 = apunta con claridad. 1 = solo desempata. Las expresiones de varias palabras pesan más que las sueltas, porque son más específicas.
